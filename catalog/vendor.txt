# Software published on its maker's own site instead of GitHub releases:
# proprietary apps and tools, and a few open-source ones that are only
# distributed this way.
#
#   name  https://homepage  key=value ...
#
# url.<platform>=URL    the official download link for one platform; url.macos=
#                       sets both Macs (a universal build). Links may redirect:
#                       one that lands on a stable, versioned file is pinned as
#                       that file; one that lands on a signed, expiring URL stays
#                       the original link. {version} is replaced by the version.
# version-url=URL       a page that names the current version (an update feed)
# version-after=TEXT    the version is the text right after TEXT on that page, or
#                       in the final download URL when there is no version-url.
#                       Without either, the version is read from the final URL,
#                       else from the file's Last-Modified date (YYYY.M.D).
# app=, win=, bin=, desc=, license=   as in sources.txt (license defaults to
#                       Proprietary).
#
# The builder downloads every file, pins its SHA-256 in the signed catalog,
# finds the app or programs inside and runs the malware scan, as for any
# source. abv0 refuses a download whose SHA-256 differs, so a vendor that
# replaces a file under the same link is picked up by the next daily build.
#
# Mac: .dmg and .zip apps (not .pkg installers). Windows: portable .zip only.
# Kept sorted within each section.
